# TaskMada: A Clean, Simple Kanban To-Do List

Welcome to TaskMada! This is a personal project I built because I wanted a more intuitive way to manage daily tasks without the clutter of traditional to-do apps. It's a Kanban-style board that focuses on what matters: moving things forward.

## 🚀 What’s Inside?

I built this using a modern stack to ensure it’s not only fast but also extensible. Here’s a quick overview of the features:

- **Interactive Kanban Board**: Organize your tasks into Backlog, In Progress, Review, and Done.
- **Seamless Drag & Drop**: Powered by `@dnd-kit`, making reordering and moving tasks feel natural.
- **Quick Filtering**: Use the built-in search bar to instantly find tasks by title or description.
- **Priority Indicators**: Easily distinguish between high, medium, and low priority tasks.
- **Responsive Design**: Built with Material UI (MUI), it looks great across different screen sizes.

## 🛠 Tech Stack

I chose these tools because they allow for a robust developer experience and a smooth user interface:

- **React + Vite**: For a lightning-fast development environment.
- **Redux Toolkit (RTK)**: Managing global state, including task persistence and optimistic updates.
- **Material UI (MUI)**: For a clean, professional design system.
- **TypeScript**: Ensuring type safety throughout the application.

## 🏁 Getting Started

To get the project running locally, follow these steps:

1.  **Install dependencies**:
    ```bash
    pnpm install
    ```
2.  **Start the development server**:
    ```bash
    pnpm dev
    ```
    (Note: You might also need to start the backend server if you're using one for persistence.)
